# Audytor

Wersja 0.7.0+11.

Najważniejsze funkcje:
- obiekty i audyty,
- usterki ze zdjęciami,
- obowiązkowa tabliczka znamionowa albo oznaczenie jej braku,
- potwierdzenie usunięcia usterki z obowiązkowym komentarzem, datą i opcjonalnymi zdjęciami,
- raport PDF w układzie 1 × 4 usterki na stronę,
- zdjęcia w PDF zachowują proporcje,
- dodatkowe strony zdjęciowe pokazujące wszystkie zdjęcia,
- ponowne generowanie raportu po zmianach,
- eksport paczki audytu z PDF, galerią HTML i skompresowanymi zdjęciami,
- import paczki na innym urządzeniu w celu reaudytu/weryfikacji.
