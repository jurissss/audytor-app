# Audytor App

Wersja 0.5.0.

Najważniejsze funkcje:
- obiekty z unikalnym numerem/kodem, wyszukiwaniem, edycją i usuwaniem,
- lista ostatnich audytów,
- audyty z usterkami i dokumentacją zdjęciową,
- automatyczna kompresja zdjęć zapisywanych w aplikacji (do ok. 1920 px, JPEG),
- zakończony audyt pozwala potwierdzić usunięcie każdej usterki,
- potwierdzenie usunięcia zapisuje datę, wymaga komentarza i opcjonalnie zdjęcia,
- potwierdzenie można później edytować lub cofnąć,
- lżejszy PDF: do 4 zdjęć na stronę i kompresja stron do JPEG,
- PDF można wygenerować ponownie w dowolnym momencie z aktualnymi statusami,
- eksport całego audytu do jednej skompresowanej paczki `.audyt.zip`, przygotowanej do wysłania e-mailem,
- import paczki na innym telefonie w celu potwierdzania usunięcia usterek,
- ponowny import tej samej paczki aktualizuje istniejący audyt zamiast tworzyć duplikat,
- przy aktualizacji na telefonie źródłowym zachowywane są oryginalne zdjęcia usterek, a dodawane są dane i zdjęcia potwierdzające ich usunięcie.
